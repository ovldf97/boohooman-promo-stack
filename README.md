## The rules that decide whether your code actually works

boohooMAN's code system is stricter than most fashion sites, and knowing these rules upfront saves a lot of checkout frustration.

**One code per order, full stop.** You can't stack a 10% code on top of a 30% code. What you *can* do is stack a single code with the site's own promotions and free delivery offers — so the smart play is to shop the sale section first, then apply your one code on top of already-reduced prices.

**Some codes exclude already-discounted items.** Certain codes don't apply to sale stock or special collections. The product page usually flags whether an item accepts an extra discount — worth a two-second check before you fill a bag with sale items and pin your hopes on a code.

**Some codes are tied to a delivery method.** A code might only work with standard or two-day delivery and refuse to apply if you've selected next-day. If a valid-looking code fails, try switching your delivery option before giving up on it.

**App and website codes don't always match.** boohooMAN runs app-exclusive offers, and a code found on the website sometimes won't apply in the app (or vice versa). If a code fails on one, try the other. The app also gets exclusive discounts and early access to weekly drops, so it's worth having regardless.

**Typing matters.** Codes are case-sensitive and space-sensitive. Copy-paste instead of retyping.
